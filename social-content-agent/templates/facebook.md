# Facebook — תבנית

## עקרונות
- קהל: קצת יותר מבוגר, אוהב עומק
- Caption: 8-20 שורות מותר
- Hashtags: 3-5 בלבד
- שאלות פתוחות = engagement גבוה

## פוסט רגיל
```
[הקשר — מחבר לחוויה יומיומית]

[גוף — הסבר, ערך, תובנה]

[שאלה פתוחה לתגובות]

#hashtag1 #hashtag2
```

## הכרזת סדנה
```
[תאריך + מיקום]
[מה חוויים בסדנה]
[למי מיועד]
[לינק בתגובה]
[שאלה: "מי מצטרף?"]
```
