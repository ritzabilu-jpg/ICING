# ICING — אסטרטגיית שיווק

## מטרות עיקריות
- הכנסה חודשית יעד: ₪100,000
- מקורות: סדנאות קבוצתיות (60%), טבילות פרטיות (25%), קורסי מדריכים (15%)
- ערוצי לידים: טופס אתר, WhatsApp, פניות ישירות, רשתות חברתיות

## Pipeline
```
ליד נכנס → סיווג אוטומטי → טיוטת מענה → אישור ידני → שליחה → מעקב → המרה
```

## פרסונות לקוח
1. **מנהל HR** — מחפש אירוע חברה ייחודי, חשוב לו ROI ולוגיסטיקה
2. **ספורטאי/מתאמן** — מחפש התאוששות ושיפור ביצועים
3. **חובב בריאות/תודעה** — סקרן, מחפש חוויה טרנספורמטיבית
4. **פיזיותרפיסט/מטפל** — מחפש שיתוף פעולה מקצועי

## מסרים מרכזיים
- HR: "חוויה קבוצתית שזוכרים — מדע מאחורי כל רגע"
- ספורטאי: "התאוששות מהירה יותר, ביצועים גבוהים יותר"
- חובב בריאות: "כנס למים, צא אחרת"
- מטפל: "נהיה שותפים — הידע שלך + הפרוטוקול שלנו"

## תדירות תקשורת

- לידים בינוניים: 24 שעות
- לידים קרים: 72 שעות
