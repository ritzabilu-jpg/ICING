# תבניות הודעות מאושרות

## עקרונות ניסוח
- פתיחה בשם: "היי [שם],"
- הכרת הבקשה בשורה אחת
- שאלה אחת ברורה
- חתימה: "ליאור"
- אורך: 4-6 שורות
- לא urgency מלאכותית
- לא ביטויים רפואיים פסקניים

## תבנית 1: סדנה קבוצתית
```
היי [שם],
תודה שפנית! נשמע שאתם מחפשים חוויה קבוצתית מיוחדת.
כמה אנשים בתוכנית לסדנה, ומה התאריכים הנוחים לכם?
ליאור
```

## תבנית 2: טבילה פרטית
```
היי [שם],
תודה שפנית — שמחתי לשמוע!
מתי נוח לך לקבוע, ומה הניע אותך לפנות דווקא עכשיו?
ליאור
```

## תבנית 3: follow-up אחרי 48 שעות ללא תגובה
```
היי [שם],
רציתי לוודא שקיבלת את ההודעה שלי.
יש שאלות שתרצה שנבהיר? אני כאן.
ליאור
```

## תבנית 4: שאלה רפואית
```
היי [שם],
תודה שפנית — שאלתך חשובה לי ואני רוצה לענות עליה בצורה הנכונה.
אחזור אליך ישירות בקרוב.
ליאור
```

- "מבצע מוגבל! הירשם עכשיו!"
- שליחה בלי אישור ידני
